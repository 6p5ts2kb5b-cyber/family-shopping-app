# 予定タブ仕様（今日／明日／週末／週間）｜わが家のメモ

> 計画用ブランチ `stage2-plan` の文書です。段階1の2台確認が終わるまで `main` には入れません。
> ロジック：`lib/schedule-views.js`、テスト：`tests/schedule-views.test.mjs`（21件）＋ `tests/quick-schedule.test.mjs`（35件）

## 1. 画面構成（ChatGPT案を採用＋補強）
- 下のタブは **今日／予定／家族** の3つのまま。
- 予定タブの上部に **今日｜明日｜週末｜週間** の4つ切り替え（1つ約85px、文字15px、高さ44px以上）。
- 予定タブを開いたときは **前回選んだ表示** を出す（初回は「今日」）。
- 左右スワイプでも前後に移動（今日→明日、今週末→来週末、今週→来週）。上のボタンに指を伸ばさなくてよい。
- 予定の追加は右下の ［＋予定］（親指の位置）。各日の見出しにも ［＋ 追加］ を置き、その日付が入った状態で開く。

## 2. 週末
- 土曜・日曜を **縦に並べたカード**（ChatGPT案）。
- 上に ［今週末 10/17〜18］［来週末 10/24〜25］ の2つのボタン。日付も書くので迷わない。さらに先はスワイプ。
- 「今週末」の定義：月〜金は次の土日、**土・日の当日は「その週末」**（日曜に開いても昨日の土曜が見える。過ぎた予定は薄く表示）。
- 1行の表示：［出発 6:00 / →17:00］［夫］［野球大会］。時刻は左にそろえて縦に目で追える。
- 1日の並び：出発時刻順 → 時刻未定は最後 → 同じ時刻は 夫・妻・家族 の順。
- 1日に5件以上：4件まで表示し ［ほか1件を表示］。
- 予定が0件の日：「予定なし」と ［＋ 追加］ だけ。

## 3. 週間（月〜日）
- 7日を1枚のリスト。今日の行は淡い緑。
- 1日3件まで（人・予定名・出発→帰宅）、それ以上は「ほかN件」。行をタップ → その日の一覧（追加・編集）。
- ［‹ 前の週］［次の週 ›］は画面下側に置く。

## 4. 重なりの扱い
- **夫と妻の予定が重なるのは普通**なので何も出さない。
- **同じ人の予定が重なったときだけ**、小さく「〇〇と時間が重なっています」（入力ミスの発見用。保存は止めない）。
- 帰宅未定は出発から1時間とみなす。出発未定は判定しない。夜勤（22:00→6:00）は日またぎとして判定。

## 5. ホームの週末欄
| 曜日 | 表示 |
|---|---|
| 月〜水 | 出さない（ホームを短く保つ） |
| 木・金 | 「今週末 10/17〜18」を **最大2件**＋「ほかN件」→ 週末表示へ |
| 土 | 「明日（日）」を最大2件 |
| 日 | 出さない（今日の予定に出ている） |
| 予定0件 | 「今週末の予定はまだありません ＋予定を追加」 |

## 6. 色・文字・配置
- 人の色は今のまま：夫＝青、妻＝橙、家族＝緑（色＋文字ラベルで区別。色だけに頼らない）。
- **土曜を青・日曜を赤にしない**（夫の青・妻の橙と混ざるため）。曜日は灰色の文字。
- 文字：日付見出し18、予定名17、時刻17（等幅数字）、補足13〜14。
- 押せる所はすべて44px以上。カード角丸20、余白16。

## 7. 文章入力の追加対応
| 入力 | 結果 |
|---|---|
| `土曜 BBQ 10:00` | 次の土曜（土曜当日なら今日） |
| `来週土曜 運動会 8:00`、`来週の火曜 健診` | 来週（月〜日）のその曜日 |
| `週末 BBQ`、`来週末 キャンプ` | 土日どちらか **選んでもらう**（勝手に決めない） |
| `日 洗車` | 「日」1文字は曜日と読まない（日付は空欄） |
| 日の［＋ 追加］から入力 | その日付が入った状態。文章に別の日付があれば確認 |

## 8. データ・費用・安全
- データの形・Firestoreルールは **変更なし**（`familySchedules` の5項目のまま）。旧 `me` は夫として表示、書き換えない。
- 読み取り回数を抑えるため、予定は **「今日の7日前以降」だけ** を購読（単一項目の条件なので追加の索引不要）。無料枠（1日5万回の読み取り）に対して家族2人なら十分少ない。
- 外部の有料サービスは使わない。
