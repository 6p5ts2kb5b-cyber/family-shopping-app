# 試用版（app.html）実機確認チェックリスト

URL：https://6p5ts2kb5b-cyber.github.io/family-shopping-app/app.html

## ⚠ 大事な注意
- 試用版は **今の買い物リスト・予定と同じデータ（本番のFirestore）** を使います。
- 試用版で追加・変更・削除した内容は、**従来版（shared.html・schedule.html）にもそのまま反映** されます。
- 試しに登録するものは **「テスト」で始まる名前** にしてください（例：テスト牛乳、テスト予定）。終わったら試用版か従来版で削除してください。
- 本物の商品・予定は、間違えて消さないよう試用中は触らないでください（消しても6秒以内なら「元に戻す」で戻せます）。
- 従来版へは、画面上部の「従来版に戻る」または家族タブのリンクから戻れます。
