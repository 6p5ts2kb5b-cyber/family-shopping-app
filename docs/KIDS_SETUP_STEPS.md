# 伝言板を使い始める手順（承認後に行う）

**準備手順（まだ実施しない）**。本番公開前には現行ルールを安全な場所にコピーして保管し、既存の買い物・予定が動くことを確認してください。新ルールは匿名登録を有効にしても既存の権限を緩めない設計ですが、実機確認後に正式切替します。

## ① 匿名ログインを有効にする（PC・1回だけ）
1. https://console.firebase.google.com/ を開き、プロジェクト「family-shopping-app」を選ぶ
2. 左のメニュー「Authentication」→ 上のタブ「Sign-in method（ログイン方法）」
3. 「新しいプロバイダを追加」→「匿名」→「有効にする」をオン →「保存」
   - 無料（Sparkプラン）のまま使えます。「アップグレード」は押さないでください

## ② 新しい版を公開（承認後に Claude が行う）
- kids-messages-implementation を main に反映し、公開サイトの確認テストを行います

## ③ ルールを貼り替える（PC・1回だけ）
1. https://6p5ts2kb5b-cyber.github.io/family-shopping-app/setup.html を開き、管理者の Google でログイン
2. 「ルールをコピー」を押す
3. Firebase の「Firestore」→「ルール」で、今の文字を全部消して貼り付け →「公開」
   - 買い物・予定・名簿のルールは変わりません（伝言板の分が追加されるだけ）
   - ②の公開から③までの間は、伝言タブに「ルールの更新が必要」と出るだけで、買い物・予定は普通に使えます

## ④ 家族の呼び名を入れる（スマホ・1回だけ）
1. わが家のメモ →「家族」タブ →「家族の呼び名」
2. 夫・妻・子ども1〜3 の名前を入れて「保存」
   - 名前は Firebase にだけ保存され、公開されるプログラムには書きません
   - 入れるまでは「夫・妻・子ども1」などと表示されます（予定のデータは変わりません）

## ⑤ 家のタブレットを登録（1回だけ）
1. タブレットで https://6p5ts2kb5b-cyber.github.io/family-shopping-app/kids.html を開く
2. 共有ボタン →「ホーム画面に追加」（iPad）／メニュー →「ホーム画面に追加」（Android）
3. ホーム画面の「でんごんばん」から開くと、QR と絵が3つ出る
4. 管理者のスマホの**標準カメラ**で QR を読み取る → わが家のメモが開く
5. タブレットに出ている絵を4つの中から選び、タブレットの名前を入れて「このタブレットを登録する」
6. タブレットが伝言の画面に変われば完了。次からはアイコンを押すだけ
   - 解除は「家族」タブ →「子ども用タブレット」→「解除」
   - タブレットを子ども専用にするには：iPad は「アクセスガイド」、Android は「アプリの固定」


## ⑥ 登録解除・オフライン時の注意
- 子ども用伝言板は安全優先のため、起動時にインターネット上で登録を確認する必要があります。オフラインだけでは伝言を表示しません。
- 管理者が端末登録を解除すると次回オンライン確認後に閲覧できなくなります。ただし以前に保存・撮影された情報まで遠隔で完全削除することはできません。
- 端末内データを消すと匿名ログインIDが変わり、再登録が必要になることがあります。

## ⑦ 公開前確認・問題時の復旧
1. Firebaseコンソールで現在適用中のルール全文を別途保存（UIDを公開GitHubに保存しない）。
2. ルールの追加前後で既存の買い物・予定・家族名簿のログインと閲覧・編集を確認。
3. 新画面は匿名ログイン有効化・ルール適用後にのみ実機テスト。アカウント・端末登録権限を最優先で確認。
4. 問題があれば新機能の使用を停止し、保存したルールをFirebaseコンソールに戻す。既存の買い物・予定の保存内容は削除しない。
5. 実機QR登録、端末再起動、登録解除、回線切断・再接続、カメラ読み取りが確認できるまで「本番利用確認済み」と言わない。
